这版改了什么

  • 结构对齐：磨砂 blur 底 → swirl → 环内粒子 → 内嵌进度环 → 百分比，层序与 ui/style.css 完全一致；进度环内收 6.7%，不再顶在最外层。
  • 配色回归：进度环用回现版四色渐变（#4ade80 → #22d3ee → #8b5cf6 → #d946ef），颜色不随用量变化；只把同色 drop-shadow 从 3px 加厚到 3px+8px 双层，亮一档。
  • 粒子 confined 在环内：上升光尘（最多 26 枚，主题色轮换）+ 3 颗环游星带渐隐拖尾，全部画在环内缘半径以内，画布本身是圆形裁剪。
  • 新增亮点：进度弧末端一枚小白光点（贴环内侧、已缩小），兼当读数指针。
  • 最外层游星：贴球体外缘一圈一颗小星反向慢转（对应现版 .orb-orbit 位置），带主题色微光。
  • 性能不变：粒子单画布、数量封顶、DPR ≤ 2、只动 transform/opacity、页面隐藏暂停 rAF、reduced-motion 静态降级——与现版同一套约束。
